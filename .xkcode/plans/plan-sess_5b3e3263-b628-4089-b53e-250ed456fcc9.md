## ESP32 API findings
- Existing `GET /api/status` provides sensor readings and lamp/pump states; `POST /api/command` supports explicit lamp and pump on/off. `GET /api/config`, `POST /api/moisture`, and `POST /api/time` are also present.
- There is no weather-forecast route, nor a dedicated ambient-air temperature sensor route. Forecasts will come from Open-Meteo; the reported DS3231 temperature is chip temperature. API access is unauthenticated plain HTTP: use a trusted network and do not expose it to the Internet.
